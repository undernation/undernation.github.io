## 구조

- `index.html`·`privacy_policy.html`: 현재 개인정보처리방침
- `privacy-*.html`: 날짜별 이전 안내
- `terms.html`·`support.html`·`delete-account.html`: 이용 안내
- [autoever](autoever): 별도로 제작한 정적 포트폴리오 페이지와 문서 뷰어

## 확인·배포

HTML 파일은 브라우저에서 바로 열 수 있습니다. GitHub Pages는 `main` 브랜치의 루트 디렉터리를 기준으로 사용합니다.

문서의 링크·시행일과 서비스 설정을 함께 확인하며 관리합니다. 앱 소스 코드는 이 저장소에 포함하지 않습니다.
